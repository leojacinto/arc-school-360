# Arc School 360

School intelligence skills for Arc — portfolio attention monitoring, single-school check-in briefs, evidence chains, equity assessments, and action recommendations.

## Skills

| Skill | Purpose |
|-------|---------|
| school-360 | Full 360-degree school profile (identity, health, contacts, sentiment, staffing, compliance, initiatives) |
| school-attention | Regional rollup — flags schools by risk/compliance/staffing/sentiment, generates radar chart |
| school-actions | Recommended prioritised actions for a school |
| school-equity | Digital profile and equity risk assessment |
| school-evidence | Evidence chain traversal behind flagged issues |
| school-notes | Personal school notebook (OneDrive) |
| school-programs | Active initiatives/programs at a school |

## Workflows

| Workflow | Trigger | Purpose |
|----------|---------|---------|
| school-checkin | `/school-checkin` | Brief on a specific school before monthly check-in |
| schools-attention | `/schools-attention` | Flag schools needing attention across the portfolio |
